# 0001: Graft and GitLab compatibility

- Date: 2026-09-18
- Status: Accepted user direction
- Source: Naming and compatibility clarification
- Review trigger: Explicit product-direction change

The product name is **Graft**. It is a locally hosted GitLab alternative targeting GitLab APIs, URLs, apps and most GitLab functionality, with GitLab imports. Every occurrence of GitHub in the initial request meant GitLab; the earlier GitHub-first interpretation is superseded. No GitHub API/Actions compatibility layer is required.

Name availability has not been checked. Repository hosting, disclosure and license were not selected by this decision. Existing third-party licenses remain applicable to dependencies.
